# Mohamed Nafees R – Portfolio

React + Vite portfolio with 18 components.

## Run locally
    npm install
    npm run dev

## Build
    npm run build      # output in dist/

## Deploy (free)
- Vercel / Netlify: import the repo, build command `npm run build`, output `dist`.
- GitHub Pages: push `dist/` to a `gh-pages` branch.

## Customise
Edit `src/data.js` to add your email, GitHub, LinkedIn and LeetCode links
(empty links stay hidden). Project details are in the same file.
